# Archive

`claude-design/` : version du site produite avec Claude Design (octobre 2026), conservée pour référence.
- `site/` : les 4 pages HTML d'origine + `support.js` (runtime de templates `<x-dc>`) + `image-slot.js`.
- `sources/` : les fichiers source `*.dc.html` de Claude Design.

Les photos qui étaient encodées en base64 dans les fichiers `imgslot-*.state.json` sont désormais
dans `site/images/` (fichiers `.webp` aux pixels identiques). Les JSON ont été supprimés.

Rien dans ce dossier n'est publié.
