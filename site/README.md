# Dossier publié

Ce dossier est le site tel qu'il est mis en ligne sur https://atomes.studio (GitHub Pages).
Il est publié automatiquement par le workflow `.github/workflows/pages.yml` à chaque push sur `main` :
rien à copier à la main. Voir le README à la racine du projet pour la structure et les conventions.

Test en local : `npx serve site` depuis la racine du projet, puis http://localhost:3000.
